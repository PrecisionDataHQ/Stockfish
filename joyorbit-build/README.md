Pinned JoyOrbit builds of Stockfish19 for a separate local chess-engine process. The recipes preserve upstream source, verify the full neural-network checksum, cross-compile an API24 arm64 executable and retain the GPL and network acknowledgement. Android packaging stamps the actual stripped executable and requires native-library extraction before app-process execution. Generated binaries and network data are excluded from Git; the recorded source and network URLs remain necessary build inputs.
